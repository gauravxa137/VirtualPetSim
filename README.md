# 🐾 Virtual Pet Simulator

> A modern desktop pet game built with Python and CustomTkinter.

![Game Screenshot](screenshots/demo.png)
## ✨ Features

* **Material Design:** Dark mode, rounded corners, and dynamic colors.
* **Pet Evolution:** Raise your pet from an **Egg** to an **Elder**.
* **3 Species:** Choose between Dog, Cat, or Pikachu.
* **Economy System:** Play minigames to earn cash and buy items.
* **Dynamic Stats:** Health, Happiness, Energy, and Hygiene decay in real-time.

## 🚀 Quick Start

### 1. Install Dependencies
You need Python installed. Run this command to get the UI library:

```bash
pip install customtkinter

```

### 2. Run the Game

```bash
python material_pet_pro.py

```

## 🎮 How to Play

* **Feed & Medicate:** Use the **Shop** to buy food. Use the **Inventory** to consume it.
* **Earn Money:** Go to **Actions > Play** to win cash (costs Energy).
* **Avoid Sickness:** If Hygiene drops too low, your pet gets sick. Clean them immediately!
* **Game Over:** If Health hits 0, your pet passes away.

## 📂 Requirements

* Python 3.10+
* `customtkinter`
